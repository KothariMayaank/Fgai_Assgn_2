# Dataset provenance

Lewis Carroll, *Alice's Adventures in Wonderland*, Project Gutenberg ebook 11.

- Catalogue: https://www.gutenberg.org/ebooks/11
- Download: https://www.gutenberg.org/cache/epub/11/pg11.txt
- Retrieved: 21 October 2026
- Language: English. Genre: children's fantasy, narrative and dialogue.
- Project Gutenberg lists this work as public domain in the USA; consult the full licence retained in `alice.txt` for redistribution terms and local applicability.

The original downloaded text is retained unchanged. Training removes the Gutenberg wrapper and front matter, lowercases text, normalizes curly apostrophes and retains word tokens with optional internal apostrophes. Punctuation is omitted. Dataset checksum and actual counts are in `results/dataset.json`.
